# План: Docker-бэкенд для TaskMan

## Архитектура

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│  Browser    │────▶│  nginx:proxy     │────▶│  Backend    │
│             │     │  (port 80)       │     │  (port 3000)│
│             │◀────│                  │◀────│  + SQLite   │
└─────────────┘     └──────────────────┘     └─────────────┘
                         │
                    ┌────┴─────┐
                    │ Frontend │
                    │ (nginx)  │
                    └──────────┘
```

**Стек:** Node.js + Express + TypeScript + SQLite (`better-sqlite3`)
**Оркестрация:** docker-compose
**Прокси:** nginx (порт 80: фронтенд + бэкенд API)

## Шаг 2: Backend API (Express + TypeScript)

### Файлы

**`backend/src/types.ts`** — интерфейсы из фронтенда:
```typescript
interface TaskItem {
  id: number;
  label: string;
  type: string;
  created: string;
  info: string | null;
  maxDate: string | null;
  maxTime: string | null;
  reopen: boolean;
  timer: boolean;
  closed?: boolean;
  result?: string;
  closed_date?: string | null;
}

interface HistoryItem {
  id: number;
  type: string;
  label: string;
  text: string;
  path: string;
  date: string;
  song_length?: string;
  status: string;
  created: string;
}
```

**`backend/src/db.ts`** — инициализация SQLite:
- `better-sqlite3` (синхронная, быстрая)
- Создание таблиц при старте (если нет)
- Экспорт `db` и `sql` утилит

**`backend/src/routes/tasks.ts`**:
```
GET    /              → get all tasks (JSON array)
POST   /task/create   → create task, return { ok: true, id: number }
POST   /task/update   → update task, return { ok: true }
```

**`backend/src/routes/history.ts`**:
```
GET    /get/history   → get all history (JSON array)
POST   /history/create → create history, return { ok: true, id: number }
POST   /history/update → update history, return { ok: true }
```

**`backend/src/index.ts`** — entrypoint:
- Express app
- `app.use(express.json())`
- CORS (`cors()` middleware)
- Mount routes
- Listen on `process.env.PORT || 3000`

## Шаг 3: Docker-файлы

### `backend/Dockerfile` (multi-stage)

```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npx tsc

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY --from=builder /app/dist ./dist
EXPOSE 3000
CMD ["node", "dist/index.js"]
```

### `backend/.dockerignore`
```
node_modules
dist
*.db
```

### `nginx/nginx.conf`

```nginx
upstream backend {
    host backend;  # docker-compose service name
}

server {
    listen 80;
    
    # Frontend (static files from nginx:8080 mounted volume)
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
    
    # Backend API proxy
    location /api/ {
        proxy_pass http://backend:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # CORS headers
        add_header Access-Control-Allow-Origin *;
        add_header Access-Control-Allow-Methods 'GET, POST, OPTIONS';
        add_header Access-Control-Allow-Headers 'Content-Type';
        
        if ($request_method = 'OPTIONS') {
            return 204;
        }
    }
}
```

### `docker-compose.yml`

```yaml
version: "3.8"

services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "3000:3000"
    volumes:
      - db-data:/app/data
    environment:
      - PORT=3000
    restart: unless-stopped

  frontend:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./dist:/usr/share/nginx/html:ro  # mounted after build
    depends_on:
      - backend
    restart: unless-stopped

volumes:
  db-data:
```

### `docker-compose.dev.yml` (dev override)

```yaml
version: "3.8"

services:
  backend:
    volumes:
      - ./backend/src:/app/src        # hot reload через nodemon
      - ./backend/dist:/app/dist
      - db-data:/app/data
    command: ["npx", "nodemon", "--watch", "src", "--ext", "ts", "--exec", "ts-node src/index.ts"]

  frontend:
    volumes:
      - ./dist:/usr/share/nginx/html  # dev build из npm run build
```

## Шаг 4: Обновление фронтенда

### `backend/src/store/tasks.ts` и `backend/src/store/history.ts`

Заменить хардкод `http://192.168.1.66:3000` на переменную окружения:

```typescript
const API_BASE = import.meta.env.VITE_API_URL || '/api';
```

Или через `process.env`:
```typescript
const API_BASE = process.env.VUE_APP_API_URL || '/api';
```

**`vue.config.js`** (или `vite.config.ts`):
```javascript
module.exports = {
  devServer: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true
      }
    }
  }
}
```

## Шаг 5: Команды

### Запуск dev:
```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

### Запуск prod:
```bash
# 1. Собрать фронтенд
npm run build

# 2. Собрать и запустить всё
docker compose up --build -d
```

### Остановка:
```bash
docker compose down
# Чтобы удалить БД тоже:
docker compose down -v
```
